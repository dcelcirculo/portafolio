Proyecto para cliente 01

Sistema de Inventario y Ventas · Esmeralda Makeup

Producto web instalable que licencio a pequeñas empresas: cada cliente lo tiene en su propio servidor, con su dominio y su base de datos. Primer cliente: Esmeralda Makeup, que compra en Estados Unidos y vende en Guatemala.

  • Un solo código para todos los clientes; monedas, impuestos, logo y numeración se configuran desde la interfaz.
  • Módulos adicionales que se activan con una licencia firmada digitalmente.
  • Ventas en USD y GTQ, costo promedio y escaneo de códigos de barras con la cámara del celular.
  • Pantallas de vendedoras pensadas primero para celular; despliegue con HTTPS automático.
Python FastAPI PostgreSQL SQLAlchemy React TypeScript Docker Caddy

En uso real 02

Sistema Contable Local

Sistema de contabilidad y facturación para freelancers y pequeños negocios en Estados Unidos. Funciona sin internet, en la red local, y se usa desde la computadora o el celular.

  • Captura de recibos con OCR y revisión humana antes de guardar cada transacción.
  • Facturas en PDF; al marcar una factura como pagada se crea el ingreso automáticamente.
  • Corte de caja, reportes para impuestos (JSON y CSV) e importación de extractos bancarios.
  • Refactor que unificó tres fuentes de datos en una sola arquitectura basada en transacciones.
Python FastAPI SQLAlchemy Alembic React TypeScript Tailwind Tesseract Gmail API Docker
🔒 Código privado

Interpreter Assistant

Plataforma que automatiza mi trabajo como intérprete. Empezó como un extractor de citas de los portales de las agencias y creció a un asistente de agenda y kilometraje.
